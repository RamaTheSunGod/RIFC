# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - Initial Release
### Added
- Core logic for parsing DSL.
- Rendering algorithm for basic layout and curves.
- Multi-language support (English and Spanish).
- Customizable configuration features for GUI.
- Save and open project features in native `.txt` format.
- Code export options for Python and JavaScript.
