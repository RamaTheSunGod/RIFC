# RIFC (Rama's Instant Flow Chart)
A simple, pseudocode based, flow chart generator  // Un generador de diagramas de flujo simple, basado en pseucodigo

##Features//Caracteristicas

-Light, pseudocode2img // Liviano, pseudocodigo a imágen
-Export in svg, png and pdf // Exporta en svg, png y pdf
-3 styles (classic, modern, academic) (see preferences menu) // 3 estilos (clasico, moderno, academico)
-Dark and light theme // Tema claro y oscuro
-Language: Spanish, for now // Español, por ahora

##Tutorial

###Blocks//Bloques:

-inicio: Start // Inicio
-act: Action // Proceso
-if: Decition // Decisión
-loop: Repetitive actions // Acciones repetitivas
-fin: End // Final

See the initial example, it's pretty easy to understand // Mira el ejemplo inicial, es bastante fácil de entender
